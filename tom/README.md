# Projeto do Tom — Anúncios e Tráfego Pago

Casa do **Tom** (`.claude/agents/tom.md`). Tudo que ele planeja, mede e decide fica aqui.
Dono: Wyguivan Reyller (Equipe Maximus). O Tom chama o Wyguivan de "chefe".

## Mapa das pastas

| Pasta / arquivo | Para quê |
|---|---|
| `regras.md` | Regras do chefe (hashtags, repetição, frequência, domingo, aprovações). Mandam em tudo. |
| `status.md` | Painel: o que está conectado, o que está pendente, decisões aguardando o chefe. |
| `horarios.md` | Histórico de horários testados e o que deu certo ou errado. |
| `vencedores.md` | Posts que superaram a mediana e viram candidatos a anúncio pago. |
| `calendario/` | Calendário de postagem sem repetição (`AAAA-MM.md`) e "impressão digital" de cada peça. |
| `criativos/legendas/` | Legendas prontas, uma por rede. |
| `criativos/roteiros/` | Roteiros de vídeo (o Maximus produz o vídeo). |
| `relatorios/` | Relatórios semanais e mensais (`AAAA-MM-DD-semanal.md`, `AAAA-MM-mensal.md`). |
| `trafego-pago/` | Plano de campanhas, públicos, verba e regras de decisão (nada gasta sem OK do chefe). |
| `planejamento-2027/` | Plano anual de 01/01 a 31/12/2027, em lotes mensais. |

## Rotina do Tom

- **Segunda:** relatório semanal + checagem de horários.
- **Toda semana:** propõe o lote de posts da semana seguinte para o OK do chefe.
- **Dia 1 de cada mês:** relatório mensal.
- Antes de agendar: confere `calendario/` (sem repetição) e `regras.md`.
